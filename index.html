FAQ
Are these developer data tools really free with no login?

Yes. Every tool on this hub is free to use with no login, no signup, no email, and no credit card. They run in your browser the moment the page loads. The free tools build queries and URLs or preview data; the paid path is optional — only the backing Apify actor charges, and only if you choose to run a full extraction at scale.

What does it mean that each tool is 'backed by an Apify actor'?

An Apify actor is a hosted, production program that performs a data task — scraping, searching, or normalizing a source — at scale on Apify's cloud. The free in-browser tool helps you build the exact query or URL; when you need the full dataset, the same logic runs server-side as a paid actor. It bridges a quick free answer and a repeatable production data pull.

Why can't a free browser tool just fetch any API or website for me?

Browser security (the Same-Origin Policy and CORS) blocks JavaScript from reading responses from a different domain unless that server sends an Access-Control-Allow-Origin header. Most data APIs and sites do not. So a client-side tool can build a query or URL freely, but live data fetching usually needs a server-side proxy — which is exactly what the backing Apify actor provides.

What's the difference between a query builder and a scraper?

A query builder is a free, client-side tool that assembles a valid search URL or query string from your inputs — for example a Reddit advanced-search query or a Google Patents URL — without fetching anything. A scraper actually retrieves and structures the data. On this hub the free tool builds the query; the backing Apify actor scrapes and returns structured results when you run it.

Do my inputs leave my browser when I use these tools?

For the URL- and query-building tools, no — they run entirely client-side, so what you type stays in your browser and is never sent to a server. If a tool fetches live data from a third-party API, that request leaves your browser by necessity. Each tool page states honestly which mode it uses, including any CORS limitation.

Who builds these tools and can I trust the data logic?

They are built by Omar Eldeeb, a developer who maintains a portfolio of production data actors on the Apify Store under the handle constructive_calm. The free tools share the same query and URL logic as the live, paying actors, so what you build in the browser matches what the production actor runs.

What tools are available right now?

Three are available. The company hiring-signals tool is live — it fetches a company's open roles from a public API directly in your browser and classifies the hiring intent. The Reddit and Google Patents tools are query builders: they assemble a precise, ready-to-run query (Reddit operators like subreddit:/author:/title:; Google Patents inventor/assignee/date/classification filters) and show a fixed example of the output shape, because those sources block direct browser reads. More tools are planned from the broader actor portfolio.

Are these an alternative to extensions like Instant Data Scraper or sites like FreeDevTools?

They serve a narrower, deeper purpose. General toolboxes (FreeDevTools, DevUtils, DevToys) cover encoders, formatters, and converters; browser extensions like Instant Data Scraper grab visible page data. These tools are vertical and data-source-specific — built around one source (Reddit, Google Patents, hiring data) with a query builder up front and a production scraper behind it.

Do I need to know API or scraping code to use them?

No. The point of each free tool is to remove that requirement — you fill in fields (keywords, dates, a subreddit, an assignee) and the tool produces a valid, ready-to-use query or URL. If you later run the backing Apify actor for a full dataset, you paste the same inputs into a simple form; no code is required there either.
