# Visa sponsorship & salary data tools

> U.S. employers that sponsor foreign workers must file wage details with the Department of Labor, and those filings are published as public disclosure files. The two tools here are query builders on top of that data: one finds employers that sponsor visas for a role and location, the other turns filed wages into salary benchmarks such as median and percentiles. Each assembles a ready-to-run configuration and previews a fixed example of the output. Keep in mind this is visa-sponsored wage data, a strong signal but a subset of all U.S. jobs.

## Tools

- [Find H-1B & green-card visa sponsors + salary data](https://datatooly.xyz/visa-sponsor-finder/) (query builder): Free H-1B visa sponsor lookup query builder. Set a role + city, preview the output shape, then run it live on real DOL LCA & PERM sponsor data.
- [What does a role pay? H-1B/PERM salary benchmarks](https://datatooly.xyz/salary-benchmark-lookup/) (query builder): Benchmark what a role pays using public DOL H-1B/PERM wage disclosure data — percentiles by city, state, or employer, or individual records. Free to start.

## Guides

- [How to Build an H-1B Salary Database by Employer (with Python)](https://datatooly.xyz/guides/h1b-salary-database-by-employer/): A practical guide to querying H-1B salary data by employer and role, using the authoritative DOL OFLC LCA disclosure files with runnable Python.
- [PERM Disclosure Data in Python: Find Green Card Sponsors by City](https://datatooly.xyz/guides/perm-disclosure-data-python-green-card-sponsors/): Use the DOL's free PERM disclosure file to list green card sponsors by city and occupation in Python: where the file lives, key columns, and the traps.
