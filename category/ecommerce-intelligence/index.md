# E-commerce intelligence tools

> Most Shopify stores expose a public /products.json endpoint that returns their catalog, including titles, vendors, variants, prices and stock, with no API key and open CORS. The tool in this category fetches it live in your browser, so what you see is the store's real current catalog. Stores behind a web application firewall return an error in the browser; the tool says so plainly instead of faking results. Catalog snapshots across many stores, and change tracking over time, run on the backing Apify actor.
