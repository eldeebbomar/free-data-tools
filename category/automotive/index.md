# Used car listing data tools

> Gulf used-car marketplaces such as DubiCars and Dubizzle list thousands of pre-owned vehicles, but none offer a public export. The tool in this category is a query builder: pick the platforms, set a make and model and a per-platform cap, and it assembles a ready-to-run configuration and shows a fixed example of the listing record, with make, model, year, price in AED, mileage, GCC spec, seller type and listing URL. It does not show live listings in your browser; the export runs on the backing Apify actor.
