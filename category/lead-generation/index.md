# Lead generation data tools

> LinkedIn has no public API for profile data, but public profile pages can be read without logging in. The tools in this category are query builders for finding and extracting that public data: they assemble a ready-to-run configuration and show a fixed example of the structured output, such as name, headline, work history, education, recent posts and articles. They do not fetch live profiles in your browser. The extraction runs on the backing Apify actor, and only public information is collected; respect LinkedIn's terms and local data-protection rules.

## Tools

- [Extract LinkedIn profiles — posts & articles](https://datatooly.xyz/linkedin-profile-lookup/) (query builder): Free query builder for a LinkedIn profile scraper: paste profile URLs, preview the JSON output shape, then run it on Apify — no cookies or login.
- [Find LinkedIn profiles by job title and location](https://datatooly.xyz/linkedin-people-search/) (query builder): Free LinkedIn people search builder: enter job titles and locations, preview name, headline, company and profile URL rows, then run it on Apify. No cookies.
