# Social media & community data tools

> These tools cover public social and community data: Reddit posts and comments, Threads profiles and keyword searches, public Telegram channels and YouTube Shorts. None of these sources can be read reliably from a visitor's browser (Reddit's JSON, for example, is CORS-blocked and refused from datacenter IPs), so every tool here is a query builder. Each one assembles a ready-to-run configuration and shows a fixed example of the output shape, clearly labelled as an example rather than live results. The real extraction runs on the matching Apify actor, free to start and then pay-as-you-go.

## Tools

- [Search Reddit by keyword or subreddit — and export it clean](https://datatooly.xyz/reddit-search-builder/) (query builder): Build a Reddit keyword/subreddit search query free in your browser, preview the output, then export posts + comments to CSV/JSON. No API key, no login.
- [Extract Telegram public channel posts](https://datatooly.xyz/telegram-channel-search/) (query builder): Build a ready-to-run config to scrape Telegram channel posts, views, and reactions. Preview the output shape, then run it live on the Apify actor.
- [Scrape Threads profiles, posts & hashtags](https://datatooly.xyz/threads-profile-search/) (query builder): Free Threads scraper query builder. Configure profile, posts & hashtag scrapes, preview the output shape, then run live on Apify. No login needed.
- [Monitor Threads by keyword or hashtag](https://datatooly.xyz/threads-keyword-monitor/) (query builder): Build a Threads keyword or hashtag search, then schedule monitoring for new matching posts. Cookie-free public-web config for the Apify actor. Free to start.
- [YouTube Shorts Scraper — find viral Shorts by channel or keyword](https://datatooly.xyz/youtube-shorts-search/) (query builder): Scrape YouTube Shorts by channel, keyword, hashtag, or URL. Get exact view, like, and comment counts, viral scores, and 360p downloads — no API key or quota.
