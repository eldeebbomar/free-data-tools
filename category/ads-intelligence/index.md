# Ad library & ads intelligence tools

> Public ad libraries let you see what competitors are running, but they are built for browsing, not exporting. The two tools here are query builders for the Meta (Facebook) Ad Library and TikTok's EU Commercial Content Library, which covers the EEA, UK, Switzerland and Turkey under the Digital Services Act. Each assembles a ready-to-run configuration by keyword, country or advertiser and shows a fixed example of the ad record, such as creative, copy, advertiser and run dates. The live extraction runs on the matching Apify actor.

## Tools

- [Facebook Ad Library Scraper — search & export competitor ads](https://datatooly.xyz/facebook-ad-library-search/) (query builder): Build a ready-to-run Facebook Ad Library scraper query — keyword, country, active status — and preview the export shape, then run it live on Apify.
- [Search the TikTok Ad Library (EU/DSA)](https://datatooly.xyz/tiktok-ad-library-search/) (query builder): Build a TikTok Ad Library query by keyword or advertiser, check if your market is in the 33 EU/DSA regions, preview the output, then run it live.
