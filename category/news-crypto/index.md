# Crypto news data tools

> Crypto newsrooms publish fast, and copying articles by hand does not scale. The tool in this category is a query builder for Cointelegraph news: set a keyword, language and article count, and it assembles a ready-to-run configuration and previews a fixed example of the structured output, with titles, full text, authors, categories, dates and view counts. It does not fetch live articles in your browser. The extraction runs on the backing Apify actor, which reads the publisher's GraphQL backend and is pay-as-you-go.

- Updated: 2026-09-29

## Tools

- [Search & export Cointelegraph crypto news](https://datatooly.xyz/crypto-news-search/) (query builder): Free Cointelegraph scraper query builder. Configure keyword, language, and article count, preview the JSON output shape, then run it live on the Apify actor.

## Guides

- [Cointelegraph API: Get Crypto News as JSON Without a Key](https://datatooly.xyz/guides/cointelegraph-api-crypto-news-json/): Cointelegraph has no public news API, but its site runs on a keyless GraphQL endpoint and RSS feeds. Pull articles, search results and full text as JSON.
