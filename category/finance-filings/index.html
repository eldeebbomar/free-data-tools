Financial filings data tools

The SEC's EDGAR system publishes every U.S. public company filing, XBRL financial data and insider trades through free, no-key endpoints. The catch is that EDGAR requires a descriptive User-Agent header, which browser JavaScript cannot set, so the tool in this category is a query builder rather than a live search. It maps a ticker and a mode (filings, financials or insider trades) to a ready-to-run configuration and previews a fixed example of the output. The request itself runs server-side on the backing Apify actor.
