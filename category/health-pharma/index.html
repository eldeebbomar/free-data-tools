Health, clinical trial & pharma data tools

This category mixes one live tool and one query builder. The clinical trials search calls the official ClinicalTrials.gov v2 API directly from your browser, which needs no key and allows cross-origin requests, so the NCT IDs, statuses, phases and sponsors it shows are real. The peptide and GLP-1 market tool is a query builder: it assembles a ready-to-run configuration for consumer-demand signals from public communities and previews a fixed example of the output. Both hand off to Apify actors when you need bulk, scheduled or exported data.
