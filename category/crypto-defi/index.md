# Crypto & DeFi on-chain data tools

> Sandwich attacks and other MEV extraction quietly tax traders on decentralized exchanges. The tool in this category is a query builder for measuring that risk: choose a mode, a chain and token or pool addresses, and it assembles a ready-to-run configuration and previews a fixed example of the per-pair output, with fields such as the 24-hour sandwich rate, an MEV risk level and a fee breakdown.
